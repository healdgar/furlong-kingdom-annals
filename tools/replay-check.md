# Local replay validation

Run serial hardware Chrome comparisons against a frozen Git source and candidate file:

```sh
node tools/replay-check.mjs --baseline 405fed3 --source index.html --days 30 --seed 1001 --coast sea --driver tick --out /existing/local/evidence/replay-tick
node tools/replay-check.mjs --baseline 405fed3 --source index.html --days 30 --seed 1001 --coast sea --driver raf --out /existing/local/evidence/replay-raf
```

Each command runs fresh isolated profiles sequentially. No concurrent benchmark browsers.
Default variants are baseline,candidate; `--variants baseline` records only baseline evidence and establishes no comparative gate. `--variants baseline,candidate,legacyoff,transactionsoff` adds diagnostic controls: legacyoff injects the legacy codec flag and disables semantic transactions; transactionsoff disables only semantic transactions.
`--mode timing` omits the independent correctness runs; `--mode correctness` omits timing.
`--cadence 1` checks every boundary; larger cadence still hashes every accepted event.
`--days 90` or `270` increases coverage and resource use. `--timeout 600` bounds each run.
The output parent must already exist; default disk preflight requires 2048MiB (`--min-free-mb`).

Source HTML, source/harness hashes, Node/Chrome versions, GPU renderer and options remain local.
Profiles are generated by this harness and cleaned on success/error/signal; no unrelated profiles or evidence are removed.
The harness stores hashes and metrics, not huge raw event dumps.

All runs suppress native RAF and UI intervals during boot, pause, settle deferred visual callbacks and drain boot records before fixing the interval. Timing runs then restore native RAF explicitly, reset the animation clock and retain RAF rendering for `--driver raf` and use actual fastest player speed. Tick runs
suppress RAF and advance one complete day per command, respecting journal backpressure.
Simulation runs include journal encoding/persistence waits; end-to-end elapsed time also includes
final durable flush. Boot is outside the measured interval; encoded/stored byte totals include boot.
Per-tick nearest-rank p95/p99/max and timer heartbeat delay report responsiveness, not physical input latency.
No graph scans or expanded event capture run in timing passes. Peak pending and precise-Chrome JS heap are sampled after each tick,
so a transient larger within-tick burst can be missed. Browser startup/boot and correctness instrumentation
are excluded from timing. RAM/disk contention invalidates comparative performance conclusions.

Correctness suppresses UI intervals and uses matched monthly callback yields plus visual finish before each comparison. Start/end day counts are asserted. Separate correctness passes hash accepted expanded storage records, reconstruct them with the existing
independent reducer, compare raw own-field storage state and exact RNG stream states plus uncapped broad world/land/annal graph fingerprints at matched cadence,
and independently read/reduce/hash persisted expanded records after flush. Begin headers are excluded
from comparative event hashes. Sequence continuity and final journal durability remain required.
This is a storage-event oracle, not complete modeled-game reconstruction, hydration, continuation,
or proof that every semantic transaction field is captured. For candidates exposing FURLONG_TRANSACTIONS, an independent field reducer requires initial definitions,
checks every recorded before/after precondition without refreshing stale values, and compares final recorded
scalar and structured fields to raw resolved own properties. Arrays/holes, Map/Set order and creditor references are independently normalized; registered account/entity references also require raw pointer identity. Missing versus undefined remains distinct. Accessors are counted as skipped; only converted purse/claim/debt fields receive coverage. Unrecorded
writes causing stale fields fail rather than being hidden. Transaction instrumentation fixtures remain separate evidence.

`checks.json` reports correctness equivalence and predeclared gates: at least 70% lower total encoded
history and at least 2x end-to-end actual RAF throughput. Tick measurements cannot establish the RAF gate.
Gate failure is reported distinctly from correctness failures; JSON contains all failures, while process
exit failure denotes correctness/runtime failures. A short run does not establish mature-world safety.

The broad graph oracle follows performance-check exclusions for named derived indexes/routes and graphics, includes uncapped life/annal ledgers, Map/Set order, array holes and exact special-number tags. It is a comparison oracle, not an archive/hydrator.

Canonical storage audit capture uses FURLONG_STORAGE_AUDIT_OBSERVER only when FURLONG_STORAGE_AUDIT_SUPPORTED is true; otherwise it wraps the legacy storageOutcome function. It never installs both. Every CDP response wait has a 120-second deadline identifying the method and a bounded expression prefix.

CPU sampling with `--profile` writes a Chrome `.cpuprofile` and disables throughput clearance.
The model fingerprint excludes `__hs`, the spatial hash query deduplication stamp; fewer identical queries may change that scratch value without changing their results.
